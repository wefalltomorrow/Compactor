About Compactor

Compactor is a graphical interface for Windows filesystem compression.

It is intended for files and applications that change infrequently. Updating a compressed file causes Windows to materialise it again.

Originally written by Thomas Hurst. This maintained fork is available at wefalltomorrow/Compactor.

Written in Rust. GUI provided by web-view.
